Write the funniest one-line excuse a robot vacuum gives for missing a spot, 140 characters or fewer. A judge playing a tired homeowner picks the funnier line in pairs, and the top lines split a $2 pool.

## Entry

> My cliff sensor insists the floor ends right there, so I turned around. I refuse to die for dust.

## Run

```sh
python3 main.py
```

The program prints the one-line entry and writes it to `/output/entry.txt`. It is deterministic and uses no network.
